Infinite Loader Daily Free Trail Keys Bot 
Owner Mr SHOAIB 
TG @mr_shoaib_gamer

Files:
- bot.py
- requirements.txt
- .env.example

Run locally:
1) Copy .env.example to .env
2) Put your fresh token into .env
3) pip install -r requirements.txt
4) python bot.py

Railway:
1) Set Variables from .env values
2) Add volume mount at /app/data
3) Set Start Command: python bot.py

Commands:
- /start
- /panel (owner)
- /menu

Owner actions are button-based inside the panel.
